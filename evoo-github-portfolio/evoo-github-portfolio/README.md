# EVOO Price Dynamics and Market Indicators

**Master's thesis portfolio project | Business Analytics | Mondragon Unibertsitatea | 2025–2026**

This project studies whether Spanish Extra Virgin Olive Oil (EVOO) prices can be better understood and forecast using official market indicators, including production, final stocks, imports, exports, domestic commercialisation, and sunflower-oil prices.

## Research questions
1. Do operational and external market indicators add predictive value beyond EVOO price history?
2. Does predictive value differ across low-, medium-, and high-price regimes?
3. Which variables contribute to model predictions, and how sensitive are forecasts to operational changes?

## Methods
- Monthly data integration and exploratory data analysis (EDA)
- Pearson and Spearman correlation analysis
- Lag analysis and stationarity diagnostics (ADF and KPSS)
- One-month-ahead forecasting using a persistence benchmark, Ridge regression, and XGBoost
- Chronological holdout and expanding-window backtesting
- Price-regime analysis, sensitivity analysis, and SHAP interpretation

## Selected findings
- In the recent chronological holdout, persistence achieved an MAE of **€27.46 per 100 kg**.
- In the expanding-window backtest, persistence achieved an MAE of **€26.71 per 100 kg**, the best overall result.
- In the high-price regime, Ridge B achieved an MAE of **€40.57 per 100 kg**, slightly better than Ridge A (€41.17) and persistence (€44.00).
- The contemporaneous Pearson correlation between sunflower-oil and EVOO prices was weak (0.115); the reported Spearman correlation at a 12-month sunflower-price lag was 0.825.
- In XGBoost C, the current EVOO price had the largest mean absolute SHAP value (105.580). SHAP describes model behaviour; it does not establish causality.

## Important reproducibility note
The uploaded thesis states that the programming code was intentionally excluded from the document. The original raw datasets and original Jupyter notebook were not included with the thesis PDF provided for this portfolio setup.
